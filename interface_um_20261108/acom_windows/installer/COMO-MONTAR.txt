Montagem da edição de teste no Windows x64

Extraia o código-fonte em uma pasta de trabalho. Use o CPython 3.14 x64 instalado pela distribuição oficial para Windows, incluindo Tcl/Tk, e o compilador do .NET Framework 4.x que acompanha o Windows. A montagem usa makecab.exe e o serviço nativo Windows Installer. Consulte a licença no arquivo LICENSE-IALD.txt.

Forneça o diretório da interface da Bancada à opção --ui. O ZIP inclui a fonte da interface em web/. Para refazer o instalador com todas as cenas inclua também em web/src/ os arquivos de mídia da mesma edição da Bancada. Na edição instalada, a pasta web já os contém.

Exemplo no PowerShell, a partir da pasta das fontes

  py -3.14 sample.py downloads --codec app
  py -3.14 build_release.py --ui web --out downloads

O script calcula os resumos dos conteúdos e emite o manifesto local em build-info/last-build.json. Os metadados emitidos pelas ferramentas Microsoft podem variar entre montagens. Para conferir a cópia desta edição, use o SHA-256 do arquivo efetivamente entregue.

O pacote de instalação usa os recursos do Windows para instalar apenas na conta atual, oferecer os comandos opcionais do Explorador, registrar-se em Aplicativos instalados e remover os arquivos do produto. A especificação da Microsoft para os valores por usuário fica em https://learn.microsoft.com/windows/win32/msi/registry-table.
