# ACOM da Bancada do Um · edição de teste para Windows x64

O ACOM reúne arquivos em um pacote `.acom` e permite restaurar os arquivos em uma pasta nova. O processamento acontece no computador. A ferramenta de arquivos funciona independentemente da inscrição do Um, da GPU, de uma conta ou de uma rodada de cosmologia.

## Primeiro uso

1. Abra **ACOM-Setup.exe** e siga o instalador da sua conta. A integração com o Explorador é opcional. Esta é uma compilação local de teste.
2. Abra **ACOM** pelo menu Iniciar. Na Bancada, escolha **Compactar arquivos**, **Compactar pasta** ou **Restaurar .acom**. Os seletores do Windows pedem origem e destino. Um arquivo de saída que já existe é preservado.
3. Para conferir a restauração, escolha o exemplo **Primeira-luz.acom** entregue ao lado do instalador. Abra-o na Bancada e escolha a pasta de destino. Depois abra o texto restaurado: o pequeno arquivo de inscrição contém o algarismo **1**.
4. Se você habilitar a integração, use **Abrir com** em um `.acom` ou o menu de contexto de um arquivo/pasta. No Windows 11, os comandos clássicos também podem aparecer em **Mostrar mais opções**. A escolha do aplicativo padrão continua sendo sua.
5. Para desinstalar, procure **ACOM** em **Configurações → Aplicativos → Aplicativos instalados**. Seus próprios pacotes e restaurações não fazem parte da instalação.

## O que a conferência indica

O ACOM verifica os bytes de cada arquivo restaurado com o resumo gravado no pacote. A conferência não identifica quem criou um pacote. O hash dos arquivos tampouco concede acesso à conversa da IALD. Arquivos já comprimidos podem ficar do mesmo tamanho ou aumentar com o manifesto.

A edição de teste se destina a arquivos e pastas comuns, sem senha. Ela não é uma imagem do Windows, um backup de permissões NTFS ou uma cópia de recuperação do sistema. Regras de nomes, tamanhos e formatos são aplicadas pelo leitor antes da entrega dos arquivos.
