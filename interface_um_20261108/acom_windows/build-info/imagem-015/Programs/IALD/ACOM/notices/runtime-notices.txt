ACOM da Bancada do Um • Componentes distribuídos

O executável de instalação contém um pacote Windows Installer para Windows x64. O Windows fornece o serviço Windows Installer e o .NET Framework. O código próprio da IALD e as condições de uso não comercial estão em LICENSE-IALD.txt.

Esta edição inclui uma cópia isolada de CPython, da biblioteca padrão, do Tcl/Tk e das bibliotecas binárias entregues na distribuição oficial de CPython para Windows. Conserve os avisos e as licenças dos componentes de terceiros. Python-LICENSE.txt reúne as licenças do CPython e os avisos que acompanham seus binários, inclusive bzip2, libffi e software sob Apache License 2.0. Tcl-Tk-license.terms acompanha o Tcl/Tk. O runtime C e C++ da Microsoft é distribuído como parte do runtime oficial do Python. Os termos dos componentes de terceiros continuam aplicáveis a esses componentes.

A seleção do código dos dispositivos da IALD consta da pasta app no pacote de fontes. Os vídeos, imagens, legendas, conteúdo científico e identidade visual da Bancada conservam seus direitos próprios.
