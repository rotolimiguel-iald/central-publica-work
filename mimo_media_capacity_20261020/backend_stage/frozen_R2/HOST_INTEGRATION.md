# Host integration — staging only

Parent owns `iald_web_server.py`, worker guards and the final Goodall budget merge. This front does not edit the server or `iald_app_spend.py`.

1. Import `Scope`, `PrivateMediaStore`, `PrivateMediaRuntime`, `client_capabilities`, `resolve_media_metadata`, `contains_refs`, `reject_worker_media` from `private_media_store`. Import `validate_upload` from `iald_mimo_multimodal`. Construct one store in the protected runtime directory `.iald_runtime/private_media`, never under public/static/download roots. Existing runtime filesystem ACL must restrict service-user data. DPAPI encrypts contents; metadata is local SQLite. Do not expose its paths.
2. `authorize_scope(scope: Scope) -> bool` is a **local host identity** check: current authenticated owner, current account generation and a valid owner-scoped conversation namespace. New CID on first upload is allowed; do not require prior job or globally claim a CID. The database indexes owner+generation+conversation together. Do not accept owner/generation from query/body, media_scope, filename or a model. Do not call Bancada/network to authorize.
3. `host_scope(conversation_id: str) -> Scope` derives owner and generation from the exact same authenticated account-generation binding used for ACOM. If that binding is a compound opaque principal, retain it as `owner` and pass the account generation explicitly from existing host identity policy. Do not hash/display PII on the client; expose only `client_capabilities(scope)['media_scope']`. It partitions IndexedDB/drafts by account generation; it is not a bearer or an authorization token.
4. `register_private_media(app, store, host_scope=..., authenticate_csrf=..., upload_eligible=...)` registers POST `/api/private-media?conversation_id=...` (raw binary) and GET metadata-only `/api/private-media/<media_ref>?conversation_id=...`. `authenticate_csrf() -> bool` uses existing authenticated app/CSRF policy **without reading the body**; `upload_eligible(scope) -> bool` checks local account eligibility, not model consent autogrant. A picker/upload before renewed consent is allowed; actual transmission still requires MiMo2/Auto3 and wallet. No raw-download URL route exists.
5. Parent must add `_RequisicaoIALD.max_content_length` branch for POST `/api/private-media` returning **37_499_904**, before body parsing. Keep global `MAX_CONTENT_LENGTH` and every other route unchanged. The adapter never assigns this read-only property: it verifies `request.max_content_length == MAX_RAW_BYTES`; otherwise503. Reject missing/too-large Content-Length before body reads. Preserve auth/CSRF ordering and ensure no earlier generic global-length guard rejects this one route. Chat JSON remains bounded to2_000_000 bytes for this new protocol; oversized legacy history is refused visibly, never truncated. No broad increase of global Flask/body limits.
6. Upload returns canonical `{type:'iald_media',media_ref,kind,mime,bytes,duration_seconds,sha256,expires_at:null,width,height,has_audio}`. Client stores references in conversation history; local raw blobs may live in account-partitioned IndexedDB only. No raw localStorage Base64. `MAX_RAW_BYTES` leaves128bytes for a data-URI header under decimal50_000_000. Provider request JSON guard is separately64_000_000 bytes.
7. Create `runtime = PrivateMediaRuntime(store, scope, authorize_dispatch=host_dispatch_ok, worker=False, rates={'input':configured_input,'cache_read':configured_cache,'output':configured_output}, video_policy=None, intent_limits=None)` in the authenticated host. `host_dispatch_ok() -> bool` rechecks local rights, current-generation match, MiMo2 and Auto3 when automatic, wallet task admission and revocation. Never autogrant consent. Pass runtime explicitly to background work; no implicit ContextVar/thread inheritance. Rates come from configured host MiMo model, not client/model payload.
8. Before ACOM admission/routing: `canonical = runtime.canonicalize(client_messages, provider='mimo')`. It resolves/authenticates metadata only, rejects altered client facts and assistant refs. `resolve_media_metadata(canonical, store=store, scope=scope, provider='mimo', worker=False)` provides the trusted duration/dimensions/streams/encoded size to Goodall/JEV. No decryption occurs. Existing request summary now recognizes `iald_media`; only the derived metadata/prompt goes to JEV, never expanded bytes. New worker/nonMiMo guard: `reject_worker_media(messages, provider=destination, worker=is_worker)` **before credentials, native tokenizers, routing or model dispatch**. Scope-aware media selection can choose MiMo manager; do not reinterpret unavailable media as text.
9. `wire_messages(client, verified_science_prefix, profile, provider='mimo', images_authorized=consent_ok, media_authorized=consent_ok, private_media=runtime)` preserves canonical refs through ACOM. Pass the same `private_media=runtime` into `Evaluation.stream(...)` and, where used, `observe(..., messages=canonical, private_media=runtime)`. Existing `iald_routing_metrics.stamp` receives a host-only modality compatibility view, without bytes; exact model identity remains unchanged. The new private module has no provider callback/URL/network fetch.
10. Before `choose`, build full host body with TGL/history/tools/ACOM retained and call `plans = runtime.routing_options(body, intent_limits=host_intent, proposals={'default':{'fps':2,'media_resolution':'default'},...})`. Both private refs and legacy inline audio/video get measured metadata; legacy is not re-ingested into blob storage. Only `iald_media_budget.routing_options(plans)` goes to JEV: no refs, hashes or bytes. Parent supplies `media_budget_options` to Goodall choose, validates its answer, calls `selected = runtime.select_routing_policy(choice_key)`, and carries selected plan on its host receipt/context. This selection is not consent or wallet admission. Every `_api` round then calls `runtime.admit(body,maximum,window)` using the one shared `iald_media_budget.plan_request`; it revalidates actual final text/tools/history under the selected video policy. It does not keep a second estimator. Output-field JSON overhead is included before the plan text-size pin. `reserve(spending,body,plan)` invokes Goodall `reserve_existing`, requiring the coordinator's `spending.before(...,media_plan=plan)` merge; no edit of app_spend in this front. `expand(body,provider='mimo',plan=plan)` verifies Goodall fingerprint/output, canonical metadata and exact video policy; only then reads/decrypts blobs into the final HTTP copy. No expansion for JEV/ACOM/metrics/wallet. A plan with `vendor_frame_cap_applied` is refused: choose another explicitly proposed FPS or refuse, never silently truncate duration coverage. Actual usage settles existing ledger. Local resolution failures call `discard_undispatched()` and do not append a fake dispatched call. No retry after uncertainty.
11. Bytes are capped to the whole50MB data URI, not50MiB;64MB complete MiMo JSON is checked before POST. `app_memory.http_call` archives response bytes, not a raw request-body mandatory record. Parent must ensure the existing technical artifact limit is at least64MB **without moving raw uploads into q/ACOM**. No scientific prefix, history, required state or output is shortened to make an upload fit.
12. Retention is until explicit deletion, `expires_at:null`. Storage quota (default1GB per owner-generation/500MB per conversation), rate8 uploads/minute and4 concurrent uploads, plus64MB free-disk reserve, are local explicit admission policy, not provider duration limits. Unpublished upload intents have PID+process-birth identity and a300-second technical lease. `reconcile_uploads()` at store creation/admission marks proven-dead/expired unpublished intents `abandoned`, removes only their unpublished `.tmp/.bin`, and preserves tombstones. It does not reap live unexpired uploads, active attachments or conversations. Missing lease schema refuses and requires explicit migration; no silent schema upgrade. Publication writes temp/rename and activation under one exclusive DB transaction after state/lease/auth recheck, so explicit revocation cannot resurrect a blob. No auto expiry of retained media.

On explicitly authorized conversation deletion, call `store.revoke_conversation(scope)`; on account deletion call `store.revoke_account(scope, authorize_account_deletion=local_privileged_callback)`. Call before destroying the identity needed to identify its namespace. It revokes refs and deletes blobs, preserves technical tombstones, does not edit other conversations. Surface any storage-deletion failure; do not claim a successful purge silently. No raw paths/client-controlled filename can select a blob.
